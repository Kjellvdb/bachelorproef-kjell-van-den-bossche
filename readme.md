# Bachelorproef - Kjell Van Den Bossche

Deze repository bevat de documentatie, onderzoeksresultaten en projectbestanden voor mijn bachelorproef aan HOGENT (Hogeschool Gent).

## 🎯 Over het project

- **Onderwerp:** Automatische detectie en classificatie van partijdigheid in artikelen van Het Laatste Nieuws
- **Doel:** Het onderzoeken en ontwikkelen van een AI-gedreven oplossing die journalistieke partijdigheid in nieuwsartikelen van Het Laatste Nieuws (HLN) automatisch kan detecteren en classificeren. Hierbij wordt onderzocht hoe artificiële intelligentie en machine learning kunnen worden ingezet om nieuwsinhoud te analyseren en inzichtelijk te maken.
- **Student:** Kjell Van Den Bossche
- **Opleiding:** Toegepaste Informatica - AI & Data Engineering
- **Instelling:** HOGENT - Hogeschool Gent

## 🛠️ Technologieën & Ontwikkelomgeving

Het project maakt gebruik van de volgende technologieën en tools:

- **Programmeertaal:** Python (voor AI-gerelateerde componenten, waar van toepassing)
- **AI & Machine Learning:** Modellen voor de automatische detectie en classificatie van journalistieke partijdigheid.
- **Browserextensie:** Browsergebaseerde gebruikersinterface voor de analyse van HLN-nieuwsartikelen.
- **Documentatie:** LaTeX voor het opstellen van de bachelorproef, het onderzoeksvoorstel en de projectposter.
- **Containerisatie:** Docker voor een reproduceerbare LaTeX-compilatieomgeving.
- **CI/CD:** GitHub Actions voor automatische compilatie van projectdocumenten.
- **Ontwikkelomgeving:** Windows 11, Visual Studio Code en Git.
